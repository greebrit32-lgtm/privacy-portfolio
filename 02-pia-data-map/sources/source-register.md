## Collection notes (2026-11-03)
- **Press releases are not orders.** S04–S06 summarize FTC complaints and orders. Allegations are the FTC's, not findings of law. Cite the orders themselves if exact terms are needed.
- S07 is written for federal agencies ("Agencies should…"). This project uses the nine principles as a **risk lens** for a private company, not as legal requirements.
- uscode.house.gov returned "Page Not Found" for §45, so the govinfo 2024 edition is used (S03).
